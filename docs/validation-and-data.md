# 使用限制与数据说明

[返回 README](../README.md) · [English](validation-and-data.en.md)

## 使用限制

- 当前主要支持 Windows 上的单用户、单主机使用，部分工具路径需要按本机环境调整。
- 在线表格执行已实现腾讯文档；金山/WPS、飞书和微信接入尚未实现。
- 表格需要有可读取的表头和可唯一定位的本人行；复杂分区、保护区域及不同编辑器布局不能保证支持。
- 手机通知使用后台轮询，系统或厂商可能延迟或结束同步，进程被回收后的自动恢复与全天可靠性仍待完善。
- 主机需保持联网且不睡眠。技术早报定时需单独开启；私网联通不代表 QQ 已登录。
- v2 中断恢复与浏览器会话互斥仍需完善。写入开始后结果不明会进入 `outcome_unknown`，应先核对，不能盲目重复写入。
- Android 原生库当前构建目标为 arm64，debug APK 供测试，正式发布签名尚未配置。

## 数据与凭据

账号配置、个人资料、SQLite、附件、浏览器和私网会话存放在本机 `.private/`，由 `.gitignore` 排除。私有 `.env` 文件、数据库旁文件、签名文件、日志和主要构建产物也不应提交；脱敏配置模板、依赖锁文件和 Gradle wrapper 可以随源码提供。

DeepSeek 负责部分消息分析、字段映射和早报摘要，请求会发送处理所需内容；字段映射包含裁剪后的表头和本人行。本地存储不等于全部计算离线。图片 OCR 当前在本机运行。

手机私网连接使用独立设备令牌，主机主令牌不下发给新配对手机。令牌、邀请、二维码和会话不得放入公开截图或日志；丢失手机时应撤销业务设备权限和对应私网节点。

GitHub 只保存受版本控制的源码，不会备份被忽略的私人数据。数据库与会话应单独备份；对外发布前应检查完整 Git 历史，而不仅是当前目录。

运行和配对步骤见 [运行与连接说明](setup.md)。
